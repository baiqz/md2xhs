# Markdown → 小红书多页图片笔记

把一份 Markdown 文稿，一键排版成小红书多页图片笔记 —— 自动分页、自动断行，可整包下载。

**在线使用：<https://baiqz.github.io/md2xhs/>**

纯静态单页应用，**没有后端、没有依赖、不联网**。所有排版与出图都在你的浏览器里完成，
文稿和图片不会离开你的电脑。

---

## 功能

### 排版与出图
- **实时预览**：左边输入 Markdown，右边立刻出图；改配色、字号、比例都是即时的
- **自动分页**：按内容高度智能分页，标题不会被孤零零留在页底
- **中文断行禁则处理**：行首不出现标点、行尾不出现开括号（不是简单按宽度切）
- **预览即所得**：所有尺寸按画布宽度等比计算，预览（900px）与导出（1080/1440/2160px）分页结果完全一致

### 一键下载
- **下载全部（ZIP）**：导出一个压缩包，里面是 `01.png ~ 0N.png`，按顺序命名，直接拖进小红书就能发
- **逐张下载 PNG**：也可以只挑某几张
- ZIP 打包是内置的纯 JS 实现，不依赖任何第三方库
- 快捷键 `Ctrl + S` 直接打包下载

### 外观
| 项 | 可选项 |
| --- | --- |
| 配色主题（12） | 奶油拿铁 · 樱花粉 · 薄荷绿 · 莫兰迪蓝 · 暗夜黑 · 复古报刊 · 千禧紫 · 元气橙 · 森林绿 · 高级灰 · 深海蓝 · 黑白极简 |
| 版式风格（6） | 极简留白 · 圆角卡片 · 杂志栏目 · 手账格纹 · 大字标题 · 渐变氛围 |
| 字体（5） | **衬线** · **非衬线** · 圆体 · 楷体 · 等宽 |
| 画布比例（4） | 3:4 竖版（小红书常用） · 4:5 竖版 · 1:1 方形 · 9:16 长图 |

配色与版式**互相独立**，可以自由组合出 72 种外观；字号、页边距、输出清晰度也可调。

### 封面
- 封面页含标题、副标题、署名、日期、总页数
- **封面配图**：固定在封面顶部，版式是死的，不用手动摆
  - **位置固定**：左右各留 10% 宽度、上边留 10% 高度，图片底边正好落在画布 **1/3** 处
  - 4 种样式：圆角矩形 / 直角 / 圆形（带主题色描边+光晕）/ 拍立得（白相纸+底部留白，相框即该区域）
  - 4 档大小：在 1/3 版式上微调 **0.8× / 1× / 1.2× / 1.4×**
  - 图片**裁切填满**该区域（和朋友圈封面同理：不留白、不拉伸变形）
  - 3 种添加方式：点击选图 / 把图拖进来 / `Ctrl + V` 粘贴剪贴板里的图
  - 文字区在配图之下垂直居中；标题过长时**优先自动缩小标题字号**保住这个版式，极端长度才压缩配图，永不溢出画布
- 结尾页文案可自定义（默认「点赞 · 收藏 · 关注不迷路」）
- 页码、页眉署名可分别开关

### 编辑
- **Markdown 快捷键**：选中文字按 `Ctrl+B` 加粗、`Ctrl+I` 斜体，不用手敲标记；再按一次同一快捷键即取消格式
- **格式工具栏**：加粗 / 斜体 / 删除线 / 高亮 / 行内代码 / 链接 / H1~H3 / 列表 / 引用 / 代码块 / 表格 / 分割线 / 图片 / 清除格式，鼠标点一下就行
- **智能回车**：在列表或引用里回车自动续下一行（有序列表还会递增序号），空条目再按一次回车就退出列表
- `Tab` / `Shift+Tab` 整行缩进 / 反缩进；`Ctrl+S` 直接打包下载
- 点工具栏右侧「⌘ 快捷键」可随时查看全部快捷键

| 快捷键 | 作用 | 快捷键 | 作用 |
| --- | --- | --- | --- |
| `Ctrl+B` | 加粗 | `Ctrl+Alt+1/2/3` | 一 / 二 / 三级标题 |
| `Ctrl+I` | 斜体 | `Ctrl+Shift+8` | 无序列表 |
| `Ctrl+U` | 高亮 `==` | `Ctrl+Shift+7` | 有序列表 |
| `Ctrl+Shift+X` | 删除线 `~~` | `Ctrl+Shift+9` | 引用 |
| `Ctrl+E` | 行内代码 | `Ctrl+Shift+K` | 代码块 |
| `Ctrl+K` | 链接 | `Ctrl+Alt+0` | 清除本段格式 |
| `Enter` | 列表 / 引用续行 | `Tab` `Shift+Tab` | 缩进 / 反缩进 |

> Mac 上把 `Ctrl` 换成 `⌘`。

### 其他
- 拖入 `.md` 文件直接导入（拖图片则识别为封面配图）
- 所有设置自动记住，下次打开还在
- 上传的封面图会先压缩再存本地，不会撑爆浏览器存储

## 支持的 Markdown 语法

`# H1` `## H2` `### H3` · `**加粗**` `*斜体*` `~~删除线~~` · `` `行内代码` `` · `==高亮==` ·
`[链接](url)` · `- 无序列表` · `1. 有序列表` · `> 引用` · ```` ```代码块``` ```` ·
`| 表格 |` · `---` 分割线 · `![](图片URL)`

> `# H1` 会被用作封面标题，`H1` 下面的第一段短文字会被用作封面副标题。

## 用法

### 在线用（推荐）
打开 <https://baiqz.github.io/md2xhs/> 即可，手机浏览器也能开。

### 本地用
下载这个仓库，**双击 `index.html`** 就行 —— 不需要装任何东西、不需要起服务器。

### 改完代码怎么重新发布
双击 `publish.bat` 即可（它会列出改动、提交、推送）。GitHub Pages 会自动重新构建，
约 1 分钟后刷新线上地址就能看到新版本。

## 关于测试

浏览器里跑 Canvas 出图，肉眼很难发现问题。所以这里有一套**离线渲染测试台**：
用 `@napi-rs/canvas` 把浏览器里的 canvas 代码**在 Node 里真跑并输出 PNG**，
直接检查排版结果，比在浏览器里截图可靠得多。

```bash
npm i @napi-rs/canvas
cd _test
node test-render.js   # 多配色/版式/字体组合出图
node cover.js         # 封面配图冒烟（样式 × 图源 × 大小 × 画布比例）
node coverlayout.js   # 封面配图版式几何断言：用品红测试图逐点取像素，验证左右上 10%、底边 1/3
node edge.js          # 边界用例：空文稿、超长表格、超长无空格串、各画布比例…
node editcheck.js     # 编辑快捷键：纯函数用例 + DOM 桩模拟真实按键与工具栏点击
node diag.js          # 打印每页每个条目的 x/y 坐标，定位分页问题
node domcheck.js      # 静态校验 index.html 的 id ↔ app.js / editor.js 的选择器、CSS 完整性
```

编辑快捷键那套逻辑（`js/editor.js`）刻意做成了**纯函数**：输入「文本 + 选区」，输出
「新文本 + 新选区」，不碰 DOM，所以能在 Node 里直接断言光标位置 —— 快捷键最容易出的
问题不是"没反应"，而是"文本对了但光标乱跳"，只测文本是测不出来的。
